# Созданиия аудио плагина
# 1.цель создание кроссплатформенный аудиоплагин обрабатывающий звук в реальном времени
# 2.что мне нужно: 
1.язык программирования C++ 2.фреймворк Juce 3.среда разработки Visual studio 4.формат плагинов VST3 стандарт и AU для Mac 5.Инструментный дизайн Figmas
# 3.из чего состоит плагин: 
1.Audio Processor это (мозг) плагина тут происходи математика звука.
Input входящий аудиобуфер (массив сэмплов)
Processing Изменение Сэмплов (фильтрация, дилей, искажение)
Output отправка измененных сэмплов в DAW формате ( Ableton, FL Studio)
2.Editor (GUI) Визуальная оболочка. 
ручки, кнопки, слайдеры, которые пользователь крутит мышкой.
3.State Management Сохранение настроек. Чтобы при закрытие проекта в DAW вск ручки  оставались на своих местах
# 4.выбор идеи Эквалайзер(EQ)
3-полосный эквалайзер с регулятором Low,Mid,High. Позволяет понять основы фильтрации
